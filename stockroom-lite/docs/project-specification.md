# Project Specification

## Objective
Build a lightweight inventory management system for a small shop with one admin user role.

## Functional Modules
1. Login
2. Dashboard
3. Products
4. Categories
5. Suppliers
6. Stock In
7. Stock Out
8. Reports

## Key Requirements
- JWT-based admin authentication
- Password hashing
- CRUD operations for products, categories, suppliers
- Product image upload
- Stock movement tracking and automatic quantity updates
- Low stock alerts
- Dashboard totals and inventory value
- Inventory and sales reporting with PDF export

## Non-Functional Requirements
- Input validation on all write APIs
- Standard API response envelope
- Centralized error handling
- Separation of backend/frontend/docs

## Workflow
1. Data model design
2. Backend APIs
3. Frontend pages + API integration
4. Validation and error fixes
5. Documentation and interview prep
